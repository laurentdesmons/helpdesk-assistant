# Software Installation Requests

## Pre-approved software
Software listed in the internal Software Center catalog can be self-installed by any employee without approval — installation is logged automatically for compliance.

## Non-catalog software
Requests for software not in the catalog require manager approval before IT will install. The request must include: business justification, expected cost (if any), and manager's name.

## Restricted categories
The following categories are never self-installable and require Security review regardless of manager approval: remote access tools, browser extensions with broad permissions, any software that handles customer PII, cryptocurrency-related software.

## Turnaround
Catalog installs: same day, automated.
Non-catalog approved installs: 2–3 business days.
Security-reviewed installs: 5–10 business days.
